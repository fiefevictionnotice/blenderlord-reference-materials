# Armor renders

**You must own Mount & Blade II: Bannerlord to use these files.**

Reference renders of Native's armor, made in Blender from `Bannerlord-Armor-Reference-Full.blend` (see
[Complete armor and weapons references](../../README.md#complete-armor-and-weapons-references)). Each item is shown on
a plain clay mannequin from three sides: `<item>_front.png`, `<item>_right.png` and `<item>_rear.png` (560 px, Blender
EEVEE).

| Folder | Contents |
|---|---|
| [`head/`](head/) | 256 helmets and head items, 768 images |

The file names are the game's item mesh names, so you can search the reference blend or the game files for them.
