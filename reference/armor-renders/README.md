# Armor renders

**You must own Mount & Blade II: Bannerlord to use these files.**

Reference renders of Native's armor, made in Blender from `Bannerlord-Armor-Reference-Full.blend` (see
[Complete armor and weapons references](../../README.md#complete-armor-and-weapons-references)). Each item is shown on
a plain clay mannequin from three sides: `<item>_front.png`, `<item>_right.png` and `<item>_rear.png` (560 px, Blender
EEVEE).

| Folder | Contents |
|---|---|
| [`head/`](head/) | 256 helmets and head items, 768 images |
| [`body/`](body/) | 241 body armors, 723 images |
| [`hands/`](hands/) | 35 gloves (framed on the right glove), 105 images |
| [`legs/`](legs/) | 39 boots and shoes, 117 images |
| [`horse/`](horse/) | 31 horse harnesses, saddles and mule loads on a clay horse, mule or camel, 93 images |

Body armors are shown in their base (male) variant; the `_converted` / `_slim` variants are only in the blend. The four
`sturgia_boots_a` .. `d` have no material in the reference blend, so their renders use the game's own textures
(`sturgia_boots_b` shares the `sturgia_boots_a` textures, as in the game).

The file names are the game's item mesh names, so you can search the reference blend or the game files for them.
